# Separate draw and scheduling — 21 October 2026

## Admin workflow

Event Details contains event dates, Match Timing, officials and Programs last. Estimated match duration and player rest are editable event-wide settings (new-plan defaults 40/120 minutes). Schedule reads these saved values and has no timing editor. Edit Dates remains visible; saved slots, started/results history and tablet bindings must be resolved before editing. An unscheduled draw alone does not lock dates. Changing the event range clears dated/repeating sessions and allocation summaries while preserving draws and seeds.

Fixture and Result opens an overview with Seeds / Participants, Stage, Draw and Schedule. Continue opens the next unfinished step for that program. Completed finals and Round Robin show completion; an eligible next knockout/group stage shows Pending draw until its own draw is saved.

The fixture workspace keeps the selected event/program and a persistent 1 Seeding → 2 Draw → 3 Schedule → 4 Fixture & Results navigation bar. Save seeding, then Continue to Draw. Choose format, preview and swap positions silently, then Confirm & Save. Swaps change the temporary preview only; errors retain alert dialogs. Drawing creates identities and structure with null dates/courts. It does not require sessions or officials. The saved matchup list has no swap controls; Continue to Schedule is the primary action after saving; Apply Draw Settings to Other Programs supports generating other eligible programs before scheduling. Export, Print and permitted resets are grouped under Options. Footer actions use one horizontal row.

Schedule is event-wide because sessions/courts are shared. It can be entered from the workspace or Schedule Event on the overview.

1. Save estimated duration and player rest in Event Details → Match Timing before scheduling.
2. Choose a date from the dropdown containing only event dates. Each session panel has Start/End, its own courts and Programs and Stages selections, plus Select All for eligible stages in that session. Add sessions with the shared primary-colour time picker. Gaps are breaks. Courts come from Master Setting; legacy event court pools do not limit availability.
3. Select current generated stages separately in each session. For example, 10am–12pm allows A, while 2pm–4pm allows A and B. Remaining A matches can use the afternoon; B cannot use the morning. Selecting the same stage in multiple sessions allows its matches to use any of those sessions; it does not duplicate matches. A stage with unscheduled matches remains selectable on other event dates. Saved match slots stay on their original dates unless an explicit move or validated swap is confirmed.
4. Configure other event dates separately. Copy Sessions and Courts to Other Days is removed. The overview shows sessions, courts and per-session requested maximums; candidate matches may be eligible in several sessions but each match can receive only one slot.
5. Preview proposed slots and Not Slotted reasons, then Confirm separately. Existing assignments remain unchanged when adding rounds; no-fit new matches stay unscheduled. The saved timetable shows actual stored date/time/court assignments.

Legacy repeating daily hours expand into individual event dates in the editor. Existing varying dated hours are copied exactly. Opening the page or editing a draft does not persist/convert anything. Confirmation saves the dated form. The planner does not require every program/round draw before scheduling selected generated rounds, and it does not invent unknown future-round fixtures or reserve future capacity.

## Independent advancement and adjustments

Every program can generate its next round when its own required results/standings permit it. The event-wide Round Progression setting and cross-program format/stage/start restrictions are removed. Legacy I/A values remain readable but cannot block another program. Own-round results, ties, BYEs, correction locks and existing later-round protection remain in force.

Example: schedule X/Y opening rounds on day one, Z on day two. Finish X while Y still plays. Generate X's next draw and add it to day two. Z's saved slots stay unchanged; shared participants/rest and own prerequisites are checked. Admins who want coordinated programs can choose to wait or schedule their next rounds on the same date.

Unplayed individual matches can still be adjusted using existing Table View schedule controls. Existing schedules, playing matches and results are never automatically moved. Move Round explicitly previews relocation of an entire stage to the selected date. Every non-BYE match must be unplayed, unpaired and free of games/corrections; all must fit before confirmation can succeed. The preview writes nothing. A stage may now continue across explicitly selected dates; only unscheduled matches are appended automatically. General bulk replanning and future-round capacity reservations are not implemented. Officials are assigned when calling a match or through existing per-match settings; the new scheduler does not silently choose an umpire. Preset selection and the complete tablet/manual result model remain unchanged.

## Validation and safety

Sessions must be nonoverlapping, entirely inside the event dates and outside ambiguous/invalid venue-time transitions. Duration is 1–360 minutes, rest 0–240 minutes. Dates, match IDs and court selections must be valid and distinct. Only active event programs may be selected. Selected matches without courts/sessions are rejected instead of disappearing from the payload. Existing session/court references are protected. New slots account for court occupation, participant conflicts/rest, recorded finish times and own-round prerequisites, and must fit entirely inside one selected day's session. Existing live/result/preset/official data is not overwritten.

Too little capacity produces a compact preview of remaining unscheduled matches. Only dates/sessions explicitly selected for that program may receive its remaining matches; no unselected date receives spillover. Preview writes no SQL. Confirm uses the existing serialized SetupStore revision/audit transaction; preview tokens expire after ten minutes and cannot be replayed. A changed match/revision requires a new preview. Unscheduled SC matches have null court/start/end, show Scheduling required in Dashboard and cannot pair, start or accept manual results. Existing backend manual overrides continue to validate conflicts.

## Rotations, session quantities, continuation and swaps — 27 October 2026

Each program/stage shows the global unallocated balance: total currently unscheduled matches minus Matches to schedule quantities across all draft sessions and dates, including the current session. The same program shows the same balance everywhere. For example, 24 pending singles with requests of 10 and 8 show 6 awaiting scheduling in every session. A session's editable maximum is its current quantity plus that global balance; requests cannot over-allocate the total. Removing a session, deselecting a program, or reducing a quantity releases that allocation immediately. Legacy overlapping defaults are capped in date/start order to avoid duplicate demand. Counts represent requested allocations, not guaranteed slots. No feasible-count cap or background scheduler calculation is applied while editing.

Quantities cap new allocations, not saved slots. Confirmation deducts fulfilled allocations from each session's outstanding quantity. Reopening does not silently request those extras again; fully fulfilled programs are deselected for new allocation, while unsatisfied quantities remain available for review. No extra matches are assigned to fill spare space beyond the requested limit. Selecting the same candidate match in multiple eligible sessions/dates does not duplicate its assignment. The planner visits selected sessions chronologically and places only still-unscheduled matches. Existing saved slots are retained. After confirming a partial schedule, select another date/session and allocate the remainder.

Group order is derived with circle-method round-robin rotations using the existing group members. Match IDs, numbers, opponents and draws do not change. Odd groups use a virtual bye only during order calculation. Within a group, earlier rotations must have slots before later rotations, whose starts follow those earlier finishes; each participant's configured rest is additionally checked. Across groups/programs, the earliest feasible candidate is preferred, then rotation, program allocation count and interleaved group/pair order. Groups do not globally wait for each other. Sessions/courts, existing matches across events, imported participant IDs, planning rest and assigned officials constrain feasibility. Officials are not silently assigned. This is a deterministic scheduling heuristic, not a guarantee of an optimal packing or of every requested match fitting. The agreed 40/120-minute defaults remain editable in Event Details; no duration/rest is reduced silently and no overrun buffer is silently subtracted.

Below the court options, Estimated capacity is calculated immediately from session duration, selected court count and event estimated match duration: floor(session minutes / match minutes) × selected courts. It is independent of program selections, participant availability, player rest and existing bookings. Thus a 14:00–18:00 session with four courts and 40-minute matches shows 24 even with no programs selected. Invalid/nonpositive time windows show zero. This is theoretical court capacity; Preview Schedule checks saved bookings, player rest, shared participants and group rotations, and reports actual fits and shortfalls. Preview reports scheduled/requested for each session/program, plus grouped Remaining Unscheduled counts with expandable match numbers. The day overview reports sums of session maximums, not distinct matches; it is labelled accordingly. A repeated candidate is still allocated only once. Matches beyond a session's chosen quantities remain available rather than being treated as a validation error.

Swap Slots is available in Review Schedule and View Saved Timetable. Choose two matches and inspect both new date/time/court destinations, retained durations and affected session program counts. Only unstarted, uncalled SC matches without games or correction history are eligible. Both matches must belong to this event. The explicit exchange can cross program selections; session match membership/day summaries are adjusted for these two matches. Quantities govern automatic allocation only. Validation rechecks session fit, closed courts, other matches, player rest, prerequisites, assigned officials and revision. Both changes succeed together or neither is saved. Longer durations must fit the destination without overlapping neighbours. Opponents, presets, scores and all other match slots stay unchanged; changed courts clear court-specific review availability. Preview swaps modify only an expiring in-memory preview and rotate its token. Saved swaps use serialized audit action SCHEDULE_SLOT_SWAP. Called/playing/review/completed matches cannot be swapped. General bulk rescheduling and live queue rearrangement remain outside this feature.
